# v4 release (24-25 Nov 2026)

- **Release commit:** `0ec5741` on branch `release/v4` (tag `v4`, local).
- **Image:** `pokercpp-v4.tar.gz`, sha256 `2d34d1517d28d37a0ba01cf3ce79cebc1b999776cf9b21ebadc156bb966be24b`.
- **Goal:** a robust, identifiable, verified v4 with no strategy change. The bench can't show how the real field plays, so strategy changes tonight would add risk with no way to measure the gain.

## Contents
- **From main:**
  - blind and `all_in` reading (`9636642`);
  - wire log fields (`199d5b8`);
  - engine fixes A2 + B (`e1d32bd`);
  - seeding and paired tooling (`42d8d18`);
  - bench through bot.py (`246fd2f`);
  - end-of-hand logging (`95820be`).
- **`a12af80`:**
  - **Big-blind read hardened:**
    - derived from pot and to_call only on our first preflop decision of a hand;
    - a hand starts at `round_start`, or when a nonzero `hand_number` changes;
    - the fixed bb is reused only when hand numbers or `round_start` messages actually arrive;
    - no derivation without `dealer_seat`;
    - a `min_raise` cross-check logs `BB MISMATCH` and never overrides.
  - **Opponent memory:** keyed by a `round_start` counter when `hand_number` is 0.
  - **Startup log:** version 4.0.0 and the commit.
  - **`STATE` lines:** for the first 50 decisions of each match.
- **`0ec5741`:** `chipzen/test_v4.py` (contract tests T1-T9), `tools/fuzz_bot.py`, and the bench's `--hand-number zero` mode.
- **Not in v4:** opponent stats (stage 1), range keying, recency memory, the push/fold table, the Metal path, and strategy tweaks.
