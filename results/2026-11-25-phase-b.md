## B1: mutation runner (H-15, #106)

**What it is.** `tools/mutants/run.py` applies one catalogued mutant at a time in a throwaway detached worktree of HEAD (outside the repo), rebuilds what the file needs, runs the named tests (the exact commands CI uses, plus `decide_properties` and `eval_exhaustive`), and records which tests exit nonzero (kill; a timeout counts as a kill). It compares the result with each entry's `expect` list. Local only, never in CI. The catalogue is `tools/mutants/catalogue.json` (23 entries, sources in `tools/mutants/SOURCES.md`).

### Review fix: baseline check, and labelled timeouts and compile errors (commit eb0dbef)
The first version never ran the tests on the unmutated base, so a test that already failed (for example engine_seed when the Python has no pytest) would count as a kill on every mutant. Now, before any mutant, the runner makes one worktree of the pinned base SHA, builds what the selected tests need, runs each selected test once, and exits 1 with `baseline failed: <test>: <last lines>` if any fails or times out; no mutant is applied. A timeout or a `make` compile error is now labelled "timeout" or "compile-error" in the matrix instead of "killed". Both still count as caught for the expect check.

- **Seen failing.** Python without pytest, `--only M8 --tests engine_seed,sdk`, exit 1, no mutant applied, git state unchanged:

The catalogue is unchanged; a D2 solver miss in a run is this flake, not a runner fault.

## B4: seed Monte Carlo on deal seed and seat (#63, #117)

- **What changed.** Harness only. Each decision's seed depends on the deal seed, the agent's own seat, its decision count in the hand, and a per-agent name salt; the View hand id is `seed * 2 + own seat`; the global `HAND_IDS` counter is gone. `split_roles` gives same-named hero and villain different salts by role, so an A/A duplicate run no longer draws identical seeds across the swap.
- **Black-box test, seen failing first.** `tools/test_seed_key.py`, 8 cases, all pass. On main (a414505) cases 1a, 1b, 2, 3, 4 failed; 5, 6, 7 passed as guards. Case 7 was also seen failing on the branch before the role salt.

- **Reviewer holds and fixes.** A hold on the `round_result` hand_number, which did not match the turn states; fixed in 713217e, and case 8 was added.
- **Old vs new, 12 dumps** (`--hero bot`, 1000 hands, s-a vs the new seeding). The draws differ by design, so the expectation is noise only; all 12 intervals contain 0 (largest: aggro 100 bb seed 710001, +25.2 bb/100, CI [-65.0, +115.5]).
