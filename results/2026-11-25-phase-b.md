# Phase B: test plan results

## B1: mutation runner (H-15, #106)

**What it is.** `tools/mutants/run.py` applies one catalogued mutant at a time in a throwaway detached worktree of HEAD (outside the repo), rebuilds what the file needs, runs the named tests (the exact commands CI uses, plus `decide_properties` and `eval_exhaustive`), and records which tests exit nonzero (kill; a timeout counts as a kill). It compares the result with each entry's `expect` list. Local only, never in CI. The catalogue is `tools/mutants/catalogue.json` (23 entries, sources in `tools/mutants/SOURCES.md`).

**Catalogue commit.** 9158d0f, made on 2026-11-25 at 18:47 ET, before any full run. Later changes to the catalogue: one entry only (below).

### Runner limits (also in its docstring)
- A compile error in a `make` test counts as a kill.
- A timeout kills only the direct child.
- The end-of-run check fails only on tracked-file changes or leftover mutant worktrees; other processes' untracked files and worktrees are printed as notes.
